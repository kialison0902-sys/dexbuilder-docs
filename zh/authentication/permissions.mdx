---
title: "权限与 Scope"
description: "对 Trading Key 与 Builder Admin 凭证执行最小权限原则。"
---

## Trading Key Scope

- `account:read`
- `orders:read`
- `orders:write`
- `positions:read`
- `positions:write`
- `funds:read`

资产提现和结算提交仍应要求对应的钱包授权载荷。

## Builder Admin Scope

- `builder:read`
- `builder:write`
- `users:read`
- `fees:read`
- `fees:write`
- `revenue:read`
- `analytics:read`
- `webhooks:write`
- `markets:read`
- `markets:write`

<Note>
  请使用当前环境凭证服务返回的 Scope 名称，拒绝未知 Scope，并仅申请接入所需的最小权限。
</Note>
