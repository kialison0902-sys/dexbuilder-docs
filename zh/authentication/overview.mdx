---
title: "认证概览"
description: "为公共、用户、钱包与 Builder 操作选择正确的授权方式。"
---

| 场景 | 授权方式 | 常见操作 |
|---|---|---|
| 公共 | 无 | 合约、行情、订单簿、成交、K 线、系统状态 |
| Trading Key | API 请求签名 | 私有账户数据、订单、仓位、杠杆与保证金 |
| ◇ 钱包签名 | EIP-712 或链原生消息 | 契约发布后的注册、提现、PnL 结算与内部划转 |
| ◇ Builder 管理权限 | 服务端授权 | 发布后的 Builder 用户、费率、交易量、订单标签与每日手续费收入操作 |

## 安全规则

- 不要在客户端代码中暴露交易 Secret 或未来的 Builder 管理凭证。
- 为每个 Key 设置最小权限与尽可能短的有效期。
- 在不改变用户钱包的情况下轮换和撤销 Key。
- 验证时间戳与 Nonce，防止重放攻击。
- 在支持时使用生产来源白名单与 IP 限制。
- 日志只记录对应契约定义的请求标识，不记录原始 Secret 或完整钱包签名。

<Note>当前交易 API 认证已发布；Builder 认证与钱包签名契约仍为 `◇`，不能根据 Orderly 路径自行推测。</Note>
