---
title: "认证概览"
description: "为公共、用户、钱包与 Builder 操作选择正确的授权方式。"
---

| 场景 | 授权方式 | 常见操作 |
|---|---|---|
| 公共 | 无 | 合约、行情、订单簿、成交、K 线、系统状态 |
| Trading Key | API 请求签名 | 私有账户数据、订单、仓位、杠杆与保证金 |
| 钱包签名 | EIP-712 或链原生消息 | 注册、提现、结算及其他用户授权操作 |
| Builder Admin | 服务端有限权限凭证 | 项目、用户、手续费、收入、分析与 Webhook |

## 安全规则

- 不要在客户端代码中暴露 Secret 或 Builder Admin 凭证。
- 为每个 Key 设置最小权限与尽可能短的有效期。
- 在不改变用户钱包的情况下轮换和撤销 Key。
- 验证时间戳与 Nonce，防止重放攻击。
- 在支持时使用生产来源白名单与 IP 限制。
- 日志记录 `request_id`，不要记录原始 Secret 或完整钱包签名。
