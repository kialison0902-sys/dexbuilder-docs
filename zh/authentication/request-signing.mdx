---
title: "请求签名"
description: "签署私有交易 API 请求并保护凭证。"
---

DexBuilder 私有交易 API 使用以下内容组成规范请求：

1. HTTP 方法
2. 请求路径
3. 规范化查询字符串
4. 请求体的十六进制 SHA-512 哈希
5. 请求时间戳

使用 API Secret 对结果签名，并随 API Key 和时间戳请求头发送。

## 规范化要求

- 使用线上实际发送的完整路径。
- 对查询参数进行一致排序和编码。
- 无请求体时对空内容进行哈希。
- 使用确定性的 JSON 序列化。
- 使用接口要求单位的 Unix 时间。
- 保持客户端时钟同步。

<Warning>
  请求头名称与规范化格式必须符合生产网关约定。上线前使用官方 SDK 或一致性测试向量验证。
</Warning>

## 钱包签名操作

注册、提现与 PnL 结算应使用域隔离的钱包消息，消息包含 `builder_id`、`chain_id`、Nonce、时间戳及对应操作字段。Transaction Builder 返回钱包需要签署的精确消息。
