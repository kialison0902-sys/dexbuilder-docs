## 提现 API

| 状态 | Method 与路径 | 说明 |
|---|---|---|
| ◇ | `GET /v1/withdraw_nonce` | 获取提现 Nonce |
| ◇ | `POST /v1/withdraw_request` | 提交已签名提现请求 |
| ◇ | `GET /v1/asset/history` | 查询提现历史 |

## 提现流程

1. 查询可提现余额与支持的目标网络；
2. 获取提现 Nonce；
3. 按提现接口结构构造 EIP-712 消息；
4. 向用户展示资产、数量、费用、网络与接收地址；
5. 获取钱包用户签名；
6. 提交提现请求；
7. 跟踪资产历史与目标链交易。

## 签名要求

正式 API 契约必须明确 EIP-712 Domain、字段顺序、Nonce 有效期、时间戳单位、数量精度、费用、状态及重试规则。客户端必须签署当前环境规定的准确消息。
