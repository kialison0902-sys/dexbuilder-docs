平仓产生已实现 PnL；PnL 结算是单独的账户操作。

<Note>`◇` 表示该操作当前尚未在 DexBuilder 开放。</Note>

## PnL 结算 API

| 状态 | Method 与路径 | 说明 |
|---|---|---|
| ◇ | `GET /v1/settle_nonce` | 获取 PnL 结算 Nonce |
| ◇ | `POST /v1/settle_pnl` | 提交已签名 PnL 结算 |
| ◇ | `GET /v1/pnl_settlement/history` | 查询 PnL 结算历史 |

## 结算流程

1. 查询账户结算资格与已实现 PnL；
2. 获取结算 Nonce；
3. 构造并签署 EIP-712 结算消息；
4. 提交结算请求；
5. 确认结算记录与结算后的账户余额。

不能根据仓位状态推断结算是否完成，必须以账户 PnL 结算历史为准。
