推荐接口用于将账户与推荐码建立关联，并允许已授权 Builder 管理推荐计划。


## 推荐码

| 方法与路径 | 说明 |
|---|---|
| `GET /v1/public/referral/check_ref_code` | 检查推荐码是否存在 |
| `GET /v1/public/referral/verify_ref_code` | 验证推荐码 |
| `POST /v1/referral/bind` | 将推荐码绑定到账户 |
| `POST /v1/referral/create` | 创建推荐码 |

## 推荐管理

| 方法与路径 | 说明 |
|---|---|
| `GET /v1/referral/admin_info` | 查询推荐码信息 |
| `POST /v1/referral/update` | 更新推荐码 |
| `POST /v1/referral/multi_level/admin` | 启用或配置多级推荐 |
| `GET /v1/referral/multi_level/admin` | 查询多级推荐配置 |

## 绑定规则

推荐关系可确定且可审计。绑定账户前，必须展示推荐关系是否永久、允许修改的条件以及返佣比例的生效时间。
