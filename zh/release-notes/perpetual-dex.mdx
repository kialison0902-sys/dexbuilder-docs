DexBuilder 通过完整的订单簿交易与接入体系，支持项目团队推出并运营具有独立品牌的永续合约 DEX。

## 已发布能力

- 公开合约、深度、市场成交、K 线、行情、指数、资金费率、保险基金与市场统计数据；
- 认证账户、账户流水、交易费率、仓位、订单、个人成交、强平与 ADL 操作；
- 单向与双向持仓模式，以及全仓与逐仓保证金流程；
- 单笔、批量、改单、撤单、倒计时撤单与档位 BBO 下单操作；
- 充值、提现、内部划转、账本对账与盈亏结算流程；
- Builder 注册、用户注册、手续费配置、用户数据、活动、推荐与收入结算。

## 接入影响

项目团队可以基于公开交易 API 构建交易界面与用户路径，并通过 Builder 工作流完成产品注册和运营。生产环境交易 API Base URL 为：

```text
https://api.dexbuilder.com/api/v1
```
