## 生产激活

1. 完成安全与架构评审。
2. 确认生产链、资产、合约地址和签名域。
3. 以最小权限创建新的生产凭证。
4. 配置生产 Webhook 地址并验证签名。
5. 确认手续费政策、用户披露、收入接收方与打款周期。
6. 使用受控小额执行完整流程。
7. 开放访问前启用监控和 On-call 升级。

## 必要监控

- API 可用性、延迟与错误率；
- WebSocket 连接、序列缺口与事件延迟；
- 订单拒绝与对账异常；
- 保证金与强平异常；
- 充值、提现与结算耗时；
- Webhook 投递失败；
- Builder 收入与打款差异。

## 上线证据

保留首笔生产注册、充值、成交、手续费、结算、提现、收入和打款的标识及脱敏截图或日志。删除 Secret 与完整签名。
