---
title: "错误处理"
description: "处理 HTTP 状态码与机器可读的 API 错误 Label。"
---

请求执行失败时，API 返回非 `2xx` HTTP 状态码，并通过 JSON 响应体说明具体错误。

## 错误响应

```json
{
  "label": "INVALID_PARAM_VALUE",
  "message": "Invalid parameter `text` with value: abc"
}
```

| 字段 | 说明 |
|---|---|
| `label` | 从公开 Label 集合中选取的稳定、机器可读错误类别 |
| `message` 或 `detail` | 说明错误原因或请求修正方式的可读信息 |

程序应根据 `label` 分支处理错误。不要解析 `message` 或 `detail` 来识别错误，因为它们的文字可能调整。

## HTTP 状态

| 状态码 | 含义 |
|---:|---|
| 200 / 201 | 请求执行成功 |
| 202 | 请求已接受，仍在处理中 |
| 204 | 请求成功，无响应体 |
| 400 | 无效请求 |
| 401 | 认证失败 |
| 404 | 未找到资源 |
| 429 | 请求频率超限 |
| 5xx | 服务端处理失败 |

## 示例

```python
import json
import requests

try:
    response = requests.get(
        "https://api.dexbuilder.com/api/v1/dex_futures/usdt/contracts/BTC_USDT"
    )
    response.raise_for_status()
except requests.exceptions.HTTPError as error:
    detail = json.loads(error.response.text)
    if detail.get("label") == "INVALID_PARAM_VALUE":
        print(f"参数错误: {detail.get('message')}")
```

联系支持时，应同时记录 `X-Trace-ID`、方法、路径、请求时间与状态码。不要发送 API Secret 或私钥。
