---
title: "限流"
description: "设计在 API 与 WebSocket 限制下保持稳定的客户端。"
---

DexBuilder 交易 API 默认允许批量、单笔、改单与撤单操作合计每秒最多 100 次请求，同时限制每个 IP 的连接数。实际接入以项目环境和接口组获配的限额为准。

## 客户端行为

- 读取限流响应头。
- 遵循 `Retry-After`。
- 将写请求排队，不要并发重试。
- 缓存稳定的公共元数据。
- 实时数据优先使用 WebSocket，不要轮询。
- 在可行时复用一个多路复用连接。
- 对重连和重试退避加入随机抖动。

<Warning>
  文档限值不代表延迟或容量保证。产生机构级订单流量前应申请专门的商业限额评审。
</Warning>
