DexBuilder 是底层交易与 Builder 基础设施。Aden 这类运营商，是构建在该基础设施之上的一种交易应用。

## 角色

| 角色 | 责任 |
|---|---|
| 交易用户 | 授权账户与资产、下单并管理仓位 |
| 应用开发者 | 构建市场、订单、账户与钱包体验 |
| Builder | 注册用户、配置产品手续费、运营 DEX 并获得 Builder 收入 |
| ◇ Builder 管理员 | 执行已发布的 Builder 用户数据、费率、交易量、订单标签与收入操作 |
| DexBuilder | 提供共享交易执行、保证金规则、账本、结算与流动性基础设施 |

<Note>
  与 Aden 一致的交易能力已经发布；Builder 能力在 DexBuilder 正式发布契约前仍为 `◇`。
</Note>
