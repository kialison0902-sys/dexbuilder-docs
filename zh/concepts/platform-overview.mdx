DexBuilder 为交易应用与品牌 DEX 前端提供交易和 Builder 基础设施。

## 角色

| 角色 | 责任 |
|---|---|
| 交易用户 | 授权账户与资产、下单并管理仓位 |
| 应用开发者 | 构建市场、订单、账户与钱包体验 |
| Builder | 上线交易前端、注册用户、配置手续费并获得 Builder 手续费收入 |
| 管理员账户 | 管理 Builder 设置，并鉴权已授权的 Builder API 操作 |
| DexBuilder | 提供共享交易执行、保证金规则、账本、结算与流动性基础设施 |

<Note>
  交易能力已进入交易 API Reference；带有 `◇` 标记的 Builder 接口当前尚未开放。
</Note>
