---
title: "结算模型"
description: "接入时必须区分的五类结算。"
---

DexBuilder 文档中的“结算”是一组不同流程，而不是一个通用操作。

| 流程 | 变化内容 | 预期证据 |
|---|---|---|
| 交易清算 | 仓位、保证金、已实现 PnL 和交易费 | 当前交易 API 数据 |
| 资金费结算 | 多空账户之间的资金费支付 | 当前账户资金费历史 |
| ◇ PnL 结算 | PnL 计入已结算账户余额 | PnL 结算历史及结果余额 |
| ◇ 资产结算 | 充值或提现达到最终状态 | 资产历史与链上交易 |
| ◇ Builder 收入结算 | 返回 Builder 每日手续费收入 | 每日手续费收入响应 |

## 接入规则

不能用市场历史资金费率证明某个用户实际支付或收取了资金费，必须查询该用户的资金费账本。

同样，不能根据一笔交易的总手续费虚构 Builder 收入公式。DexBuilder 发布后，应使用最终的每日手续费收入契约。

<Warning>
  请求钱包签名前，必须读取 API 返回的结算资格、结算后余额与可提现余额。
</Warning>
