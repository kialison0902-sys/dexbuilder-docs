---
title: "结算模型"
description: "接入时必须区分的五类结算。"
---

DexBuilder 文档中的“结算”是一组不同流程，而不是一个通用操作。

| 流程 | 变化内容 | 预期证据 |
|---|---|---|
| 交易清算 | 仓位、保证金、已实现 PnL 和交易费 | 成交与账本条目 |
| 资金费结算 | 多空账户之间的资金费支付 | 资金费账本条目 |
| PnL 结算 | PnL 计入已结算账户余额 | 结算记录与账本条目 |
| 资产结算 | 充值或提现达到最终状态 | 内部状态与链上交易 |
| Builder 收入结算 | Builder 收入变为应付或已支付 | 收入账本与打款记录 |

## 接入规则

不能用市场历史资金费率证明某个用户实际支付或收取了资金费，必须查询该用户的资金费账本。

同样，不能只用一笔交易的总手续费计算 Builder 收入。协议费、Builder 费、返佣、推荐分成及调整项都必须能够独立核对。

<Warning>
  请求钱包签名前，必须读取 API 返回的结算资格、结算后余额与可提现余额。
</Warning>
