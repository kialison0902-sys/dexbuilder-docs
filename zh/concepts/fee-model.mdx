## 费用组成

| 组成 | 支付方或接收方 | 说明 |
|---|---|---|
| 协议基础费 | DexBuilder | 基础设施交易费 |
| Builder 费 | Builder | Builder 定义的加价或 Maker 返佣 |
| 用户实际费率 | 用户 | 向用户展示的最终 Maker/Taker 费率 |
| 推荐分成 | 推荐人与被推荐人 | 分配给推荐关系参与方的 Builder 收益 |
| 资金费 | 多头或空头账户 | 市场两侧的周期性转移，不属于交易手续费 |
| 强平费 | 被强平账户 | 强平与保险基金相关费用 |
| 网络/提现费 | 提现用户 | 跨链消息、Gas 与处理费用 |

## 费率表示

DexBuilder API 结构统一使用十进制费率：

`0.0005 = 0.05% = 5 bps`

除非接口结构明确说明，客户端不能假设某个字段使用 bps。

## 用户披露

交易前展示交易 API 返回的实际费率。钱包所有者签名前，展示提现流程返回的提现费用。
