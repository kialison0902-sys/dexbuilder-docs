DexBuilder 是面向交易应用及品牌交易产品项目方的永续 DEX 基础设施。

交易 API Reference 记录当前与 Aden 对外接口一致的行情与交易能力；Builder 文档按照 Orderly 的能力模型编写，并明确标记 DexBuilder 尚未发布的部分。

## 平台接口面

| 状态 | 接口面 | 能力 |
|---|---|---|
| 已发布 | 交易 API | 与 Aden 一致的市场、订单、仓位、保证金、成交与账户数据 |
| ◇ | 钱包与结算 | 注册、Vault 充值、签名提现、PnL 结算及内部划转 |
| ◇ | Builder API | 用户归属、Builder 数据、费率配置、收入结算、推荐与订单标签 |
| ◇ | Builder WebSocket | 按 Builder 过滤的运营及用户数据流 |
