DexBuilder 为交易用户、应用开发者及上线自有交易前端的 Builder 提供永续合约交易基础设施。

交易 API 用于接入行情、订单、仓位与账户数据；Builder 文档用于接入账户注册、钱包认证、资产流程、手续费设置和 Builder 管理能力。

<Note>
  **API 可用性：**没有符号的能力已进入公开交易 API Reference；`◇` 表示该 Builder 能力当前尚未在 DexBuilder 开放。
</Note>

## 文档范围

| 范围 | 适用对象 | 内容 |
|---|---|---|
| 交易 API | 交易用户与应用开发者 | 市场、订单、仓位、保证金、成交与账户数据 |
| 核心接入流程 | 钱包与前端开发者 | 账户、认证、充值、提现、PnL 结算与内部划转 |
| Builder API | Builder 与后端开发者 | 用户数据、手续费设置、收入结算、订单标签、推荐与 Campaign |
| WebSocket API | 前端与交易系统开发者 | 公共市场数据与私有账户事件 |
