DexBuilder 为交易应用、钱包、经纪商、交易所及品牌 DEX 提供永续合约交易基础设施。

你可以使用本套文档接入行情与交易、注册用户、管理资金、结算账户、配置手续费并运营自己的 DEX。

<img src="/images/dexbuilder-cover.svg" alt="DexBuilder" />

<Note>
  请使用 DexBuilder 为项目分配的 Base URL、凭证、链配置与合约地址，并严格隔离 Sandbox 与生产环境配置。
</Note>

## 平台接口面

| 接口面 | 适用对象 | 能力 |
|---|---|---|
| 交易 API | 交易用户与应用开发者 | 市场、订单、仓位、保证金、成交及私有账户数据 |
| 资金与结算 API | 钱包与后端开发者 | 充值、提现、PnL 结算、交易构造及账本历史 |
| Builder API | 项目方 | 项目、用户归属、手续费配置、收入、分析及 Webhook |
| WebSocket API | 前端与交易系统 | 公共行情流和私有执行事件 |

## 从这里开始

<Steps>
  <Step title="选择接入路径">
    确认是通过现有运营商进行交易，还是为自己的用户构建 DEX。
  </Step>
  <Step title="在 Sandbox 开发">
    使用测试凭证和测试资产，并严格隔离 Sandbox 与生产环境凭证。
  </Step>
  <Step title="完成端到端流程">
    验证注册、入金、交易、结算、提现、错误处理和账务核对。
  </Step>
  <Step title="通过上线检查">
    确认安全、维护处理、监控、支持流程和生产限流。
  </Step>
</Steps>
