公共市场数据无需认证。

## 可用数据

| 资源 | 用途 |
|---|---|
| 合约 | 交易对、精度、杠杆、仓位限额与交易状态 |
| 订单簿 | 当前买卖报价 |
| 市场成交 | 最近成交记录 |
| K 线 | OHLCV 历史 |
| 溢价指数 K 线 | 溢价与标记价格分析 |
| Ticker 与统计 | 最新价、交易量、持仓量与市场概况 |
| 资金费历史 | 市场历史资金费率 |
| 指数成分 | 指数采用的价格来源 |
| 仓位档位 | 仓位规模与杠杆约束 |

## 快照与数据流

使用 REST 获取初始状态和进行故障恢复，使用 WebSocket 获取实时变化。

订单簿接入流程：

1. 连接公共数据流并缓存增量更新。
2. 获取 REST 快照。
3. 应用序列号晚于快照的更新。
4. 检测序列缺口，并重新获取快照恢复。

<Warning>
  当合约规范要求使用指数价或标记价时，不要用最新成交价计算强平、保证金状态或未实现 PnL。
</Warning>
