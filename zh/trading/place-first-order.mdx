## 提交前

- 读取合约元数据。
- 将价格与数量按有效步长取整。
- 检查最小下单数量和名义价值。
- 检查账户保证金、杠杆、持仓模式与风险档位。
- 确认是否必须使用只减仓。
- 在支持时分配唯一的客户端订单 ID。

## 支持操作

当前交易 API 已文档化：

- 单笔与批量下单；
- BBO 档位下单；
- 单笔与批量改单；
- 单笔、批量与全部撤单；
- 用于断线保护的倒计时全撤。

## 确认执行

提交后，通过私有数据流追踪服务端订单 ID。使用成交 ID、价格、数量、Maker/Taker 角色和手续费核对每一笔成交。

<Note>
  撤单与成交可能同时发生。最终仓位和成交记录具有权威性，不能只依据撤单响应判断。
</Note>
