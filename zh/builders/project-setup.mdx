## 配置流程

<Steps>
  <Step title="连接 Admin 钱包">
    使用由组织控制的专用钱包，在 Builder Console 完成所有权验证。
  </Step>
  <Step title="创建项目">
    定义项目名称、产品、地区、链、结算资产与接入路径。
  </Step>
  <Step title="创建 Sandbox">
    生成 Sandbox 环境与有限权限 Admin Key。
  </Step>
  <Step title="配置产品">
    设置品牌、域名、市场、手续费政策、Webhook 与运营联系人。
  </Step>
  <Step title="申请生产激活">
    完成上线评审，并创建仅用于生产环境的新凭证。
  </Step>
</Steps>

## 凭证存储

将 Admin Secret 存储在托管 Secret Store 中。记录 `key_id`、Scope、创建人、创建时间、最后使用时间和过期时间。API 创建后不得再次返回 Secret。
