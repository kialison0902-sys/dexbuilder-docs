<Warning>这是 Onboarding 要求，不是已发布的 DexBuilder API 流程。</Warning>

## 目标配置流程

1. 连接由组织控制的管理员钱包；
2. 完成 Builder 所有权及联系人验证；
3. 取得 Builder 标识和已批准的管理权限；
4. 配置支持的网络、抵押资产、市场及费率政策；
5. 在环境可用后分别创建 Sandbox 和生产凭证；
6. 通过 DexBuilder 对应的 `GET /v1/broker/broker_info` 能力验证 Builder 信息。

DexBuilder 尚未确认 Orderly 风格的 Project CRUD，因此本文档不定义 `project_id`、项目创建、部署或 Webhook 配置接口。
