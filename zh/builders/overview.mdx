**Builder** 是在 DexBuilder 上线自有交易前端并注册自有用户的团队。通过现有应用进行交易的 API 用户不需要完成 Builder Onboarding。

## Builder 生命周期

<Steps>
  <Step title="创建 Builder 资料">
    提交 Builder 名称，并选择 Low-code 或自定义 SDK/API 接入方式。
  </Step>
  <Step title="获取 Broker ID">
    完成 Builder 激活，保存用于账户注册和 Builder API 的唯一 Broker ID。
  </Step>
  <Step title="注册管理员账户">
    绑定用于管理 Builder 设置、手续费配置与 Builder API 权限的钱包。
  </Step>
  <Step title="接入核心用户流程">
    完成账户注册、API 凭证创建、充值、交易、PnL 结算与提现。
  </Step>
  <Step title="准备上线">
    验证手续费、账户隔离、签名、对账、监控与生产配置。
  </Step>
</Steps>

## Builder API 范围

| 范围 | 用途 |
|---|---|
| 用户数据 | 查询账户、持仓、订单、仓位、成交、资金费、交易量与强平记录 |
| Trading Campaign | 发布 Campaign、排行榜、统计、资格校验与报名 |
| 推荐计划 | 管理推荐码、返佣比例、Affiliate 与多级推荐关系 |
| Builder 管理 | 管理 Builder 信息、手续费、手续费收入与订单标签 |

<Note>`◇` 表示该 Builder 操作当前尚未在 DexBuilder 开放。符号只出现在对应 API 表格中，不进入导航标题。</Note>
