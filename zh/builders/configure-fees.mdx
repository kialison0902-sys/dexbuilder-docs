<Warning>本页路径是 Orderly 参考，需要 DexBuilder 开发。</Warning>

## 目标操作

| Orderly 参考路径 | 用途 |
|---|---|
| `GET /v1/broker/fee_rate/default` | 查询默认 Maker 与 Taker 费率 |
| `POST /v1/broker/fee_rate/default` | 创建默认费率 |
| `POST /v1/broker/fee_rate/set_default` | 更新默认费率 |
| `POST /v1/broker/fee_rate/set` | 设置用户级费率 |
| `GET /v1/broker/user_info` | 查询归属用户及费率信息 |

当前交易 API 的费率接口继续用于查询已认证用户的实际永续交易费率；Builder 费率管理是单独的 `◇` 能力。

发布前，DexBuilder 必须明确费率单位、精度、下限、权限、批量行为、生效时间及写后读取行为。
