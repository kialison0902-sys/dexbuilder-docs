## 配置层级

| 层级 | 优先级 | 示例 |
|---|---:|---|
| 协议基础费 | 最低 | DexBuilder 基础设施收费 |
| Builder 默认费率 | 默认 | 项目标准手续费政策 |
| 用户覆盖 | 较高 | VIP 或交易量等级 |
| 订单级费率 | 最高 | 在已启用并授权时明确指定每笔 Builder 费 |

除非有已文档化的补贴机制覆盖差额，否则 API 应拒绝低于协议基础费的 Taker 费率。

## 更新流程

1. 读取协议基础费和当前 Builder 默认费率。
2. 计算希望应用的用户实际费率。
3. 验证精度与允许范围。
4. 更新 Builder 默认值或批量更新用户。
5. 重新读取并确认已生效配置。
6. 在下一笔交易前展示实际手续费。

<Note>
  如支持订单级 Builder 费，应要求用户明确批准最高费率，并允许查询和撤销该授权。
</Note>
