## Builder 数据

Orderly 提供每日交易量、排行榜及认证的 `/v1/admin/client/*` 资源，用于查询归属用户的账户、持仓、资产、订单、仓位、资金费、交易量、强平、Algo Order 与成交数据。DexBuilder 必须逐个发布端点与结构。

## 订单归属

Orderly 提供 `POST /v1/broker/order_enum`、`GET /v1/broker/order_enums`、单项查询与更新，以及归档/恢复操作。这是 DexBuilder 订单标签的参考模型。

## 推荐、Campaign 与数据流

Orderly 还记录了多级推荐、Campaign 与 Builder 过滤的 WebSocket Topic。DexBuilder 只能在权限模型和事件契约实现后发布。

Webhook 配置及投递 API 不属于 Orderly Builder REST 对齐基线，已从本文档删除。
