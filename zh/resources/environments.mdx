## 生产交易 API

```text
https://api.dexbuilder.com/api/v1/
```

该 Base URL 仅用于已发布的交易 API Reference。

## Builder API

Builder API Base URL 与 Sandbox 配置当前尚未发布。接口开放后，Builder 接入需要以下环境配置：

- REST 与 WebSocket Base URL；
- 支持的网络与抵押资产；
- Vault 与 Verifier 合约地址；
- Broker ID 与管理员账户凭证；
- EIP-712 Domain 与签名规则；
- 限流与维护状态接口。

<Warning>不得通过替换交易 API Host 或路径前缀构造未记录的接口。</Warning>

## 环境隔离

Sandbox 与生产环境的 Broker ID、账户、API 凭证、合约地址及签名 Domain 必须相互隔离。
