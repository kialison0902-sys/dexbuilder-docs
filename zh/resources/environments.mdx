## 生产交易 API

```text
https://api.dexbuilder.com/api/v1/
```

交易 API Reference 是当前与 Aden 一致的接口契约。

## ◇ Builder 环境

DexBuilder 尚未发布 Builder API Base URL、Sandbox、Builder 签名契约或 Vault 合约集合。本文中的 Orderly 参考路径不能直接拼接到交易 API Host 调用。

去掉 `◇` 前，DexBuilder 必须发布：

- Sandbox 与生产 REST/WebSocket 地址；
- 支持的链、抵押资产与合约地址；
- 认证与签名 Domain；
- 权限、限流及错误结构。

<Warning>不得通过替换 Host 或路径前缀构造未记录的接口。</Warning>
