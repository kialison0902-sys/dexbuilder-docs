## 生产交易 API

DexBuilder 生产交易 API 使用以下 Base URL：

```text
https://api.dexbuilder.com/api/v1/
```

## 项目专属地址

接入前请向 DexBuilder 团队获取以下配置：

- Sandbox REST Base URL；
- 公共与私有 WebSocket 地址；
- Builder API 权限与项目标识；
- 支持的链与生产合约地址；
- Faucet 或测试资产获取流程。

<Warning>
  不要通过替换域名或环境名构造未文档化地址。只有环境表、API 规范或项目获配配置中出现的接口才视为可用。
</Warning>
