<Warning>
  `◇` 表示 Orderly 已有该能力，但 DexBuilder 尚未发布为可调用 API。本页所有路径都是 Orderly 的参考路径，不是 DexBuilder 接口。只有在 DexBuilder 的路径、字段、认证、签名、结构、错误与环境全部确认后，才可以移除该符号。
</Warning>

已发布的**交易 API**标签页继续保持与 Aden 对外交易接口一致；本页是单独的 Builder 开发清单。

## Builder 身份与公共查询

| 状态 | Orderly 参考路径 | 用途 |
|---|---|---|
| ◇ | `GET /v1/public/broker/name` | 查询 Builder 名称 |
| ◇ | `GET /v1/public/broker/stats` | 查询公开 Builder 统计 |
| ◇ | `GET /v1/public/volume/stats` | 查询公开交易量统计 |
| ◇ | `GET /v1/public/chain_info` | 查询支持的链与合约 |
| ◇ | `GET /v1/public/futures_market` | 查询永续市场配置 |
| ◇ | `GET /v1/public/balance/stats` | 查询公开余额统计 |

## 用户注册与交易凭证

| 状态 | Orderly 参考路径 | 用途 |
|---|---|---|
| ◇ | `GET /v1/public/account` | 检查地址是否已注册 |
| ◇ | `GET /v1/get_account` | 查询已认证账户身份 |
| ◇ | `GET /v1/get_broker` | 查询账户的 Builder 归属 |
| ◇ | `GET /v1/registration_nonce` | 获取注册 Nonce |
| ◇ | `POST /v1/register_account` | 将钱包注册到 Builder |
| ◇ | `GET /v1/get_orderly_key` | 查询交易凭证 |
| ◇ | `POST /v1/orderly_key` | 添加交易凭证 |
| ◇ | `POST /v1/client/remove_orderly_key` | 删除交易凭证 |

Orderly 的历史接口字段使用 `broker_id`。DexBuilder 产品名词统一为 `builder_id`，但开发必须先确定最终线上字段名，再发布接口文档。

## 资金、结算与内部划转

| 状态 | Orderly 参考路径 | 用途 |
|---|---|---|
| ◇ | Vault 合约 `approve` → `getDepositFee` → `deposit` | 标准保证金充值 |
| ◇ | `GET /v1/withdraw_nonce` | 获取提现签名 Nonce |
| ◇ | `POST /v1/withdraw_request` | 提交已签名提现请求 |
| ◇ | `GET /v1/settle_nonce` | 获取 PnL 结算签名 Nonce |
| ◇ | `POST /v1/settle_pnl` | 提交已签名 PnL 结算 |
| ◇ | `GET /v1/pnl_settlement/history` | 查询 PnL 结算历史 |
| ◇ | `GET /v1/transfer_nonce` | 获取内部划转签名 Nonce |
| ◇ | `POST /v1/internal_transfer` | 提交内部划转 |
| ◇ | `POST /v2/internal_transfer` | 提交当前版本内部划转 |
| ◇ | `GET /v1/internal_transfer_history` | 查询内部划转历史 |

Orderly 的标准充值通过 Vault 合约或 SDK 完成，不是创建充值单的通用 REST 资源；Orderly 也没有返回任意钱包签名负载的通用服务端 Transaction Builder。

## Builder 数据与管理

| 状态 | Orderly 参考路径 | 用途 |
|---|---|---|
| ◇ | `GET /v1/volume/broker/daily` | 查询 Builder 每日交易量 |
| ◇ | `GET /v1/broker/leaderboard/daily` | 查询每日 Builder 排行 |
| ◇ | `GET /v1/broker/broker_info` | 查询 Builder 信息与结算配置 |
| ◇ | `GET /v1/broker/daily_fee_revenue` | 查询 Builder 每日手续费收入 |
| ◇ | `/v1/admin/client/*` | 查询归属用户的账户、持仓、订单、成交、划转、资金费率、交易量与强平数据 |

DexBuilder 必须在认证与响应结构确认后，逐个发布 `/v1/admin/client/*` 端点；不能把通配符写成可调用 API。

## 手续费与订单归属

| 状态 | Orderly 参考路径 | 用途 |
|---|---|---|
| ◇ | `GET /v1/broker/fee_rate/default` | 查询 Builder 默认费率 |
| ◇ | `POST /v1/broker/fee_rate/default` | 创建 Builder 默认费率 |
| ◇ | `POST /v1/broker/fee_rate/set` | 设置用户级费率 |
| ◇ | `POST /v1/broker/fee_rate/set_default` | 更新 Builder 默认费率 |
| ◇ | `GET /v1/broker/user_info` | 查询 Builder 用户与费率信息 |
| ◇ | `POST /v1/broker/order_enum` | 创建订单归属标签 |
| ◇ | `GET /v1/broker/order_enums` | 查询订单归属标签列表 |
| ◇ | `GET /v1/broker/order_enum/{enum_id}` | 查询订单归属标签 |
| ◇ | `PUT /v1/broker/order_enum/{enum_id}` | 更新订单归属标签 |
| ◇ | `POST /v1/broker/order_enum/archive` | 归档标签 |
| ◇ | `POST /v1/broker/order_enum/unarchive` | 恢复标签 |

## Orderly 的其他 Builder 能力

| 状态 | 能力 | DexBuilder 文档要求 |
|---|---|---|
| ◇ | 多级推荐体系 | 发布角色、推荐关系、分佣、权限与结算规则 |
| ◇ | Campaign | 发布创建、资格、指标、奖励与生命周期契约 |
| ◇ | Builder 过滤的 WebSocket Topic | 发布 Topic、订阅过滤、消息结构、重放机制与限流 |

在 DexBuilder 有可验证的接口契约之前，这些只列能力，不猜测路径。

## 已从旧版草稿删除

下列内容不属于 Orderly Builder REST 基线，且 DexBuilder 尚未确认，因此已从公开 API Reference 删除：

- `/builder/v1/projects` 项目 CRUD；
- `/v1/transactions/build/*` 通用 Transaction Builder；
- `/v1/deposits` 与 `/v1/deposits/quote` 充值单 REST 接口；
- `/builder/v1/webhooks` 与 Webhook 投递管理；
- `/builder/v1/payouts` 打款创建接口；
- 通用 `/builder/v1/analytics/summary` 与自拟账本资源。

## 发布门槛

只有全部满足以下条件，才可以去掉 `◇`：

1. DexBuilder 路径与 HTTP Method 已实现；
2. 认证与钱包签名规则已确定；
3. 请求、响应、错误、精度与时间字段已评审；
4. Sandbox 与生产配置可用；
5. 端到端接入测试通过；
6. 已进入经过评审的 DexBuilder OpenAPI。
