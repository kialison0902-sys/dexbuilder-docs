## 计划中的官方产物

| 产物 | 用途 | 优先级 |
|---|---|---:|
| OpenAPI 3.1 规范 | 生成类型化客户端与交互式接口文档 | P0 |
| TypeScript SDK | 请求签名、交易 API、Transaction Builder 与 WebSocket | P0 |
| Postman Collection | 手工调试与接入支持 | P0 |
| 请求签名一致性测试向量 | 在任意语言中验证规范化 | P0 |
| React Hooks 与 UI 组件 | 钱包、市场、订单、账户与资金流程 | P1 |
| Python Connector | 量化与后端接入 | P1 |

## SDK 安全约定

官方 SDK 可以构造并提交请求，但不得收集、传输或存储用户原始私钥。钱包授权操作必须使用用户连接的钱包完成。
