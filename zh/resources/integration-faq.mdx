## Aden 就是 DexBuilder API 吗？

Aden 是基于该平台的运营商。DexBuilder 交易 API Reference 有意沿用 Aden 对外的行情与交易接口，但示例使用 DexBuilder 生产 Host。

## 现在能调用 Builder 接口吗？

不能。所有标记 `◇` 的 Builder 能力都是对齐 Orderly 的开发要求，不是已发布的 DexBuilder 端点。不要把 Orderly 路径直接拼接到 `api.dexbuilder.com`。

## 应该使用哪个手续费接口？

使用当前交易 API 查询已认证用户的永续交易费率。Builder 默认费率、用户级费率及每日手续费收入仍为 `◇`，需要等待 DexBuilder 正式发布。

## 平仓是否等于结算 PnL？

不等于。平仓产生已实现 PnL；Orderly 将 PnL 结算定义为单独的 Nonce 加签名请求，DexBuilder 仍需实现并发布。

## 是否有通用 Transaction Builder 或 Webhook API？

目前都没有已发布的 DexBuilder 契约；它们也不属于 Orderly Builder 核心 REST 对齐基线，因此不会写成可调用接口。

## 开发者现在应该接什么？

现在接入已发布的交易 API。`◇` 页面用于规划、评估 Builder 开发工作，只有对应 DexBuilder 契约发布后才能开始真实联调。
