DexBuilder 将已确认的运营商兼容交易接口与项目级 Builder 目标接口明确分开。

| 能力 | 文档状态 | 生产状态 |
|---|---|---|
| 市场、订单、仓位、账户变动、成交、实际交易费率 | 交易 API | 已在 Aden 生产网关确认 |
| 注册、链查询、充值、提现、PnL 结算、交易构造 | Builder API | 预览；待生产地址与合约 |
| Builder 项目、用户、默认/用户费率、收入、打款、分析、Webhook | Builder API | 预览；待生产激活 |
| 公共与私有 WebSocket 协议 | 接入指南 | 规划中；待最终地址、主题与恢复协议 |
| 内部划转、子账户、委托签名人、算法订单 | 架构规划 | 规划中；待接口契约 |
| 推荐、活动、积分、自定义市场/预言机管理 | 产品路线图 | 规划中；待商业与技术契约 |
| TypeScript SDK、Python Connector、UI 组件、一致性测试向量 | SDK 计划 | 规划中 |

## 生产规则

只有同时发布以下内容，接口才进入生产支持：

- 环境与 Base URL；
- 最终认证与签名规则；
- 请求与响应结构；
- 限流、错误码与状态机；
- 移除“预览”或“规划中”标记的带日期发布说明。

<Note>
  预览页面用于接口评审与实施规划，不代表接口已经开放。
</Note>
