DexBuilder 分别提供面向用户交易和项目级 DEX 运营的接口。

| 能力 | 接口 | 主要指南 |
|---|---|---|
| 市场、订单、仓位、账户变动、成交与交易费率 | 交易 API | [交易接入](/zh/trading/market-data) |
| 实时行情与私有账户事件 | WebSocket API | [WebSocket 接入](/zh/trading/websocket) |
| 注册、链、资产、充值、提现与 PnL 结算 | Builder API | [资金与结算](/zh/funds/overview) |
| 构造钱包可签名交易和类型化消息 | Transaction Builder | [Transaction Builder](/zh/funds/transaction-builder) |
| 项目、用户归属、默认与用户级手续费 | Builder Admin API | [构建 DEX](/zh/builders/overview) |
| Builder 收入、打款、分析与 Webhook | Builder Admin API | [收入与打款](/zh/builders/revenue-and-payouts) |
| TypeScript、Python、React、Postman 与签名工具 | SDK 与工具 | [SDK 与工具](/zh/resources/sdk-and-tools) |

## 环境契约

每个接入都必须读取或获取当前环境配置：

- 环境与 Base URL；
- 认证与签名规则；
- 请求与响应结构；
- 限流、错误码与状态机；
- 支持的链、资产与合约地址。

<Note>
  不同项目开通的产品与权限可能不同。请以当前环境返回的能力为准，不要从其他运营商域名推断接口支持。
</Note>
