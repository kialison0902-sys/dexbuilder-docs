## Base URL

API Reference 中的全部交易 API 路径均基于：

```text
https://api.dexbuilder.com/api/v1
```

## HTTP 方法

- 读操作使用 `GET`，只接受请求参数，不读取请求体；
- `DELETE` 用于移除订单等资源，并且不读取请求体。复杂批量撤单使用 `POST` 与 JSON 请求体；
- 更新操作使用 `POST`、`PUT` 或 `PATCH`。参数通过 query 还是 JSON 传递，以具体接口页面为准；
- 成功操作返回 `2xx`；`401` 表示认证失败，其他 `4xx` 表示请求无效，`5xx` 表示服务端处理失败。

## 时间字段

除非接口另有说明，时间字段均为 Unix 秒级时间戳，返回形式可能是整数、小数或字符串：

```text
1596531048
"1596531048"
1596531048.285
"1596531048.285"
```

需要亚秒精度时，应按支持小数的数值解析；不需要高精度时，可在解析后转换为整数。

## 网关时间

API 响应包含以下网关时间头：

| Header | 说明 |
|---|---|
| `X-In-Time` | API 网关接收请求时的 Unix 微秒级时间戳 |
| `X-Out-Time` | API 网关返回响应时的 Unix 微秒级时间戳 |

两个时间头的差值可用于区分网关处理耗时与客户端网络耗时。

## 分页

列表接口使用 `page` 与 `limit`，或者 `offset` 与 `limit`。如果接口没有特别说明，`limit` 默认值为 `100`，最大值为 `1000`。

- `page` 从 `1` 开始，持续递增，直至返回记录数小于 `limit`；
- `offset` 从 `0` 开始，每次增加 `limit`，直至返回记录数小于 `limit`。

部分列表接口还会返回：

| Header | 说明 |
|---|---|
| `X-Pagination-Limit` | 请求指定的 limit |
| `X-Pagination-Offset` | 请求指定的 offset |
| `X-Pagination-Total` | 满足请求条件的记录总数 |

## 限频元数据

不同接口可能使用不同限频规则，实际限制通过响应头返回。

| Header | 说明 |
|---|---|
| `X-RateLimit-Requests-Remain` | 当前接口与时间窗口内的剩余请求数 |
| `X-RateLimit-Limit` | 当前接口的请求上限 |
| `X-RateLimit-Reset-Timestamp` | 超限后恢复请求的 Unix 时间戳；未超限时为当前服务端时间 |

客户端应根据这些响应值实现退避与重试，不应假设所有接口共享一个固定请求频率。
