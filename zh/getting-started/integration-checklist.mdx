---
title: "接入检查清单"
description: "面向接入 DexBuilder 的 Builder 的实施与上线检查清单。"
---

## 开发前

- [ ] 选择白标、UI SDK 或直接 API 接入。
- [ ] 确认产品、链、抵押资产、地区和托管模型。
- [ ] 获取 Sandbox Broker ID 并注册管理员账户。
- [ ] 记录手续费模型和最终用户看到的费用。
- [ ] 明确钱包、后端、前端、对账、安全与支持负责人。

## 核心开发

- [ ] 使用正确的 Broker ID 为钱包所有者注册账户。
- [ ] 支持用户交易凭证的创建、轮换、过期和撤销。
- [ ] 展示合约、订单簿、成交、K 线、指数价、标记价与资金费率。
- [ ] 实现下单、改单、撤单与终态追踪。
- [ ] 实现余额、仓位、保证金、杠杆、强平与 ADL 状态。
- [ ] 根据 API 契约实现 Vault 充值、签名提现、PnL 结算和内部划转。
- [ ] 根据历史数据接口核对 Builder 每日交易量与手续费收入。
- [ ] 验证 WebSocket 重连、序列恢复和 REST 回补。
- [ ] 验证每个写操作的幂等与重试行为。

## 安全与运营

- [ ] 管理员账户凭证只存放在 Secret Manager 和后端。
- [ ] 用户授权的资产移动必须要求钱包签名。
- [ ] 配置 IP 限制、权限范围、过期时间与 Key 轮换。
- [ ] 在维护期间正确处理可撤销订单。
- [ ] 监控 API 错误率、数据流延迟、充提延迟和对账异常。
- [ ] 准备事故响应和用户支持升级路径。

## 上线

- [ ] 在生产环境用受控小额重复完整流程。
- [ ] 独立验证生产合约地址。
- [ ] 确认实际限流与预期流量。
- [ ] 验证面向用户的手续费披露。
- [ ] 确认 Builder 收入结算配置与每日手续费收入记录。
- [ ] 订阅系统与维护公告。
