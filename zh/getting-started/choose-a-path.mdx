DexBuilder 主要服务两类开发者。创建凭证之前，请先选择对应路径。

## 我想交易，或在应用中增加交易能力

以下场景应使用 **交易 API**：

- 构建交易终端或自动交易系统；
- 在钱包或现有应用中加入永续合约市场；
- 访问已经通过某个运营商交易的用户账户；
- 接入订单、仓位、账户历史或实时行情。

从[交易 API 快速开始](/zh/getting-started/trader-quickstart)继续。

## 我想为自己的用户发行一个 DEX

以下需求应规划 **`◇` Builder 接入**：

- Builder 身份；
- 用户注册以及用户归属到该 Builder；
- 默认或用户级手续费配置；
- 充值、提现与结算流程；
- Builder 范围的用户、交易量、手续费与每日收入数据；
- 订单标签、推荐、Campaign 或 Builder 过滤的数据流。

从[Builder 快速开始](/zh/getting-started/builder-quickstart)继续。

## 接入层级

| 路径 | 上线速度 | 产品控制力 | 适合对象 |
|---|---:|---:|---|
| 白标 / 无代码 | 最快 | 标准 | 需要快速上线品牌 DEX、开发量较少的团队 |
| UI SDK | 快 | 高 | 使用可复用交易组件构建自定义前端的团队 |
| 直接 API | 工作量最大 | 完整 | 钱包、交易所、经纪商、终端及深度定制产品 |

<Note>
  Builder 能力当前不可调用。未来的 Builder 管理凭证只能由受保护的后端系统使用，且不能替代用户钱包签名。
</Note>
