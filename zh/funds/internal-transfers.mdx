内部划转用于在平台内的符合条件账户之间移动抵押资产，与充值、提现及 PnL 结算相互独立。

<Note>`◇` 表示该操作当前尚未在 DexBuilder 开放。</Note>

## 内部划转 API

| 状态 | Method 与路径 | 说明 |
|---|---|---|
| ◇ | `GET /v1/transfer_nonce` | 获取内部划转 Nonce |
| ◇ | `POST /v2/internal_transfer` | 提交内部划转 |
| ◇ | `GET /v1/internal_transfer_history` | 查询内部划转历史 |

## 划转流程

1. 验证转出账户、转入账户、资产、数量与资格；
2. 获取划转 Nonce；
3. 按划转 API 构造签名请求；
4. 提交划转；
5. 在相关账户的内部划转历史中确认结果。

必须使用正式内部划转 API，不得用“提现后再充值”模拟内部划转。
