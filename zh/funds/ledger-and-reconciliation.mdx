<Warning>DexBuilder 尚未发布通用 Ledger Entry API。只能使用最终契约明确包含的历史资源。</Warning>

## 目标凭证

| 流程 | 核对凭证 |
|---|---|
| 交易 | 当前交易 API 的订单、成交、仓位、资金费与余额 |
| 充值与提现 | 资产历史及对应链上交易 |
| PnL 结算 | 对应 `GET /v1/pnl_settlement/history` 的能力及账户余额 |
| 内部划转 | 两个相关账户中对应 `GET /v1/internal_transfer_history` 的记录 |
| Builder 手续费 | 用户实际费率、Builder 每日交易量及对应 `GET /v1/broker/daily_fee_revenue` 的记录 |

DexBuilder 必须为每个数据源记录稳定标识、分页、状态、时间字段含义、修正机制与保留周期。通用账本结构及 Payout 账本不属于 Orderly 对齐基线。
