---
title: "账本与对账"
description: "核对余额、交易、资金费、资产移动和 Builder 收入。"
---

每个改变余额的事件都应生成不可变账本条目。

## 最小字段

| 字段 | 说明 |
|---|---|
| `entry_id` | 稳定的去重与对账标识 |
| `account_id` | 受影响用户账户 |
| `builder_id` | Builder 归属 |
| `asset` | 账本资产 |
| `amount` | 带符号十进制金额 |
| `entry_type` | 交易费、资金费、PnL、充值、提现、调整或其他类型 |
| `reference_type` | 成交、结算、交易、打款或调整 |
| `reference_id` | 对应来源对象 ID |
| `status` | 待处理、最终、已冲正或失败 |
| `occurred_at` | 事件时间 |

## 每日对账

分别核对：

1. 成交与订单累计成交数量；
2. 仓位变化与成交；
3. 账户余额与用户账本；
4. 充值提现与链上证据；
5. 用户实际费率与成交手续费条目；
6. Builder 收入与协议费、推荐分成扣减；
7. 应付 Builder 收入与打款记录。
