资产流程用于连接交易账户、钱包授权操作与当前环境配置的结算合约。

<Note>`◇` 表示该操作当前尚未在 DexBuilder 开放。</Note>

## 核心流程

| 流程 | 授权方式 | 确认依据 |
|---|---|---|
| 充值 | 钱包向当前 Vault 发起链上交易 | 资产历史与账户余额 |
| 提现 | Nonce 与 EIP-712 钱包签名 | 资产历史与目标链交易 |
| PnL 结算 | Nonce 与 EIP-712 钱包签名 | PnL 结算历史与账户余额 |
| 内部划转 | 按划转 API 定义完成账户授权 | 内部划转历史 |

## 接入顺序

1. 使用 Builder 的 Broker ID 注册账户；
2. 读取支持的网络、抵押资产与合约配置；
3. 构造对应操作的交易或 Typed Data；
4. 获取钱包用户授权；
5. 提交操作；
6. 使用对应历史接口确认最终账户状态。

每种资产操作都有独立请求结构。签名负载不得跨操作、网络、账户或环境复用。
