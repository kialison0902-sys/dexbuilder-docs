<Warning>资金与结算是 DexBuilder 待开发能力。在正式发布前，Orderly 参考操作不能在 `api.dexbuilder.com` 调用。</Warning>

## 目标流程

```text
注册钱包并创建交易凭证
        ↓
通过当前配置的 Vault 合约充值
        ↓
使用已发布的交易 API 交易
        ↓
提交已签名的提现、PnL 结算或内部划转
        ↓
核对平台历史与相应链上凭证
```

该模型不需要通用 REST Transaction Builder。Vault 调用及钱包签名的 EIP-712 消息应由客户端或已批准 SDK 根据正式契约构造。

精确 Orderly 参考见 [Builder API 对齐清单](/zh/resources/builder-api-alignment)。
