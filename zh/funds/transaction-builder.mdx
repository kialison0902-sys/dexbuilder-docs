---
title: "◇ 钱包操作构造"
description: "依据正式契约构造 Vault 调用与 EIP-712 消息，不虚构通用 REST 服务。"
---

<Warning>DexBuilder 尚未发布通用 Transaction Builder REST API；Orderly 的核心 Builder 模式也不要求这类接口。</Warning>

对齐后的实现按操作区分：

| 操作 | 构造方式 |
|---|---|
| 账户注册 | 获取注册 Nonce，并构造文档规定的注册消息 |
| 充值 | 构造 Token 授权与 Vault `deposit` 调用 |
| 提现 | 获取提现 Nonce，并构造文档规定的 EIP-712 消息 |
| PnL 结算 | 获取结算 Nonce，并构造文档规定的 EIP-712 消息 |
| 内部划转 | 获取划转 Nonce，并构造文档规定的签名请求 |

连接的钱包在本地签名；DexBuilder 与 SDK 都不得接收用户私钥。

如果未来要提供服务端 Payload Builder，需要单独评审接口契约，并在实现前保留 `◇`。目前不定义 `/v1/transactions/build/*`。
