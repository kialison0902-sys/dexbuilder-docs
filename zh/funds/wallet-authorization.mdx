钱包授权操作必须根据所选操作的接口结构构造。连接的钱包在本地完成签名，DexBuilder 不接收用户私钥。

## 授权方式

| 操作 | 授权方式 |
|---|---|
| 账户注册 | 包含 `brokerId` 的 EIP-712 `Registration` 消息 |
| 充值 | Token 授权与 Vault 充值交易 |
| 提现 | 使用提现 Nonce 的 EIP-712 提现消息 |
| PnL 结算 | 使用结算 Nonce 的 EIP-712 结算消息 |
| 内部划转 | 使用划转 Nonce 的签名请求 |

## 安全要求

- 使用当前环境规定的 Domain、Chain ID、Verifier Contract、字段顺序与时间戳单位；
- 签名前展示资产、数量、网络、接收地址、合约与费用；
- 拒绝过期或已使用的 Nonce；
- 提交前不得修改已签名负载；
- 不得请求、传输或保存用户私钥。

每种操作都有独立结构，不存在通用的钱包签名负载格式。
