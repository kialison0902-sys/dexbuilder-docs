<Warning>The funds and settlement surface is a DexBuilder development target. Orderly reference operations are not callable on `api.dexbuilder.com` until published.</Warning>

## Target flow

```text
Register wallet and create a trading credential
        ↓
Deposit collateral through the configured Vault contract
        ↓
Trade with the published Trading API
        ↓
Submit signed withdrawal, PnL settlement, or internal transfer
        ↓
Reconcile platform history with on-chain evidence where applicable
```

This model does not require a generic REST Transaction Builder. Vault calls and wallet-signed EIP-712 messages are constructed by the client or an approved SDK from the published contract.

See the [Builder API alignment](/resources/builder-api-alignment) for the exact Orderly references.
