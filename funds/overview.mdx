Asset flows connect the trading account with wallet-authorized operations and the configured settlement contracts.

<Note>`◇` identifies an operation that is not currently available on DexBuilder.</Note>

## Core flows

| Flow | Authorization | Confirmation |
|---|---|---|
| Deposit | Wallet transaction to the configured Vault | Asset history and account balance |
| Withdrawal | Nonce and EIP-712 wallet signature | Asset history and destination-chain transaction |
| PnL settlement | Nonce and EIP-712 wallet signature | PnL settlement history and account balance |
| Internal transfer | Account authorization defined by the transfer API | Internal-transfer history |

## Integration order

1. register the account with the Builder's Broker ID;
2. load the supported network, collateral, and contract configuration;
3. construct the action-specific transaction or typed message;
4. obtain the wallet owner's authorization;
5. submit the operation;
6. confirm the final account state from the corresponding history API.

Each flow has its own request schema. Do not reuse a signed payload across actions, networks, accounts, or environments.
