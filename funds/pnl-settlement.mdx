<Warning>The paths shown are Orderly references and require DexBuilder implementation.</Warning>

Closing a position realizes PnL. PnL settlement is a separate wallet-authorized account operation.

## Target sequence

1. request the nonce from `GET /v1/settle_nonce`;
2. construct the exact EIP-712 settlement message from the published contract;
3. obtain the user's wallet signature;
4. submit the request to the equivalent of `POST /v1/settle_pnl`;
5. query `GET /v1/pnl_settlement/history` and reconcile the resulting account balance.

Orderly's baseline does not require a separate settlement-quote endpoint. DexBuilder must publish eligibility, message fields, amount semantics, precision, statuses, and errors before release.
