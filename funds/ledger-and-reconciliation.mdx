title: "◇ Reconciliation"
description: "Reconcile Orderly-aligned platform histories with trading and on-chain evidence."
---

<Warning>DexBuilder has not published a generic ledger-entry API. Use only the history resources included in the final contract.</Warning>

## Target evidence

| Workflow | Evidence to reconcile |
|---|---|
| Trading | Orders, fills, positions, funding, and balances from the current Trading API |
| Deposits and withdrawals | Asset history plus the relevant chain transaction |
| PnL settlement | `GET /v1/pnl_settlement/history` equivalent plus the account balance |
| Internal transfer | `GET /v1/internal_transfer_history` equivalent on both affected accounts |
| Builder fees | Effective user fee, daily Builder volume, and `GET /v1/broker/daily_fee_revenue` equivalent |

DexBuilder must document stable identifiers, pagination, status values, timestamp meaning, correction behavior, and retention for each source. An invented universal ledger schema or payout ledger is not part of the Orderly parity baseline.
