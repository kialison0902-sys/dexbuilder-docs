title: "Perpetual DEX"
description: "Release of perpetual market, trading, account, settlement, and Builder capabilities."
---

DexBuilder supports the launch and operation of branded perpetual DEX products through a complete order-book trading and integration stack.

## Released capabilities

- public contract, depth, trade, candlestick, ticker, index, funding, insurance-fund, and market-statistics data;
- authenticated account, account-book, trading-fee, position, order, fill, liquidation, and ADL operations;
- one-way and hedge position modes, with cross and isolated margin workflows;
- single, batch, amendment, cancellation, countdown-cancel, and level-based BBO order operations;
- deposits, withdrawals, internal transfers, ledger reconciliation, and PnL settlement workflows;
- Builder onboarding, user registration, fee configuration, user data, campaigns, referrals, and revenue settlement.

## Integration impact

Teams can build the trading interface and user journey against the documented Trading API while using the Builder workflows for product onboarding and operations. The production Trading API base URL is:

```text
https://api.dexbuilder.com/api/v1
```
