## What is a Builder?

A Builder is a team that launches its own trading frontend on DexBuilder and registers its own users. A trading application using an existing Builder does not need Builder onboarding.

## What is a Broker ID?

Broker ID is the unique API identifier assigned to a Builder. It is used to derive account IDs, register accounts, and scope Builder API access.

## Who owns an account?

The wallet owner owns the account. A Builder admin account manages Builder settings and may query accounts registered through its Broker ID, but it cannot sign asset operations for the wallet owner.

## Does closing a position settle PnL?

No. Closing a position realizes PnL. PnL settlement is a separate signed account operation.

## Which fee record is authoritative?

Use the Trading API for an account's effective trading fee. Use daily fee-revenue history for Builder revenue reconciliation.
