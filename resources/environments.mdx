## Production Trading API

```text
https://api.dexbuilder.com/api/v1/
```

Use this base URL only with the published Trading Reference.

## Builder API

The Builder API base URL and Sandbox configuration are not currently published. Builder integrations require the following environment values when access becomes available:

- REST and WebSocket base URLs;
- supported networks and collateral assets;
- Vault and verifier contract addresses;
- Broker ID and admin-account credentials;
- EIP-712 domains and signing rules;
- rate limits and maintenance-status endpoints.

<Warning>Do not construct an undocumented URL by changing the Trading API host or path prefix.</Warning>

## Environment isolation

Keep Sandbox and production Broker IDs, accounts, API credentials, contract addresses, and signing domains separate.
