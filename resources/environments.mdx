## Production Trading API

Use the following base URL for the DexBuilder production Trading API:

```text
https://api.dexbuilder.com/api/v1/
```

## Project-specific endpoints

Obtain the following configuration from the DexBuilder team before integration:

- Sandbox REST base URL;
- public and private WebSocket URLs;
- Builder API permissions and project identifier;
- supported chains and production contract addresses;
- faucet or test-asset process.

<Warning>
  Do not construct undocumented URLs by replacing hostnames or environment names. An endpoint is available only after it appears in the environment table, API specification, or configuration assigned to your project.
</Warning>
