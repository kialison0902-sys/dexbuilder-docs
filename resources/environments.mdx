## Production Trading API

```text
https://api.dexbuilder.com/api/v1/
```

The Trading Reference is the current Aden-compatible contract.

## ◇ Builder environment

DexBuilder has not published a Builder API base URL, Sandbox environment, Builder signing contract, or Vault contract set. Orderly reference paths in these docs cannot be called by appending them to the Trading API host.

Before removing `◇`, DexBuilder must publish:

- Sandbox and production REST/WebSocket URLs;
- supported chains, collateral assets, and contract addresses;
- authentication and signing domains;
- permissions, limits, and error schemas.

<Warning>Never construct an undocumented URL by replacing a hostname or prefix.</Warning>
