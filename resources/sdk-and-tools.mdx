## OpenAPI workflow

1. pin the OpenAPI file used by your release;
2. generate or update the typed client in your build pipeline;
3. review authentication, decimal precision, enum, and error-model changes;
4. run contract tests against the configured environment before deployment.

## Security requirements

Client libraries may construct requests and wallet messages but must never request, transmit, or store a user's private key. Administrative credentials belong only in secured backend systems.
