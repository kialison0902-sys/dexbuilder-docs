DexBuilder is perpetual DEX infrastructure for trading applications and teams building branded trading products.

The Trading Reference documents the current Aden-compatible market and trading API. Builder guides follow the Orderly capability model and clearly mark work that DexBuilder has not released.

<Note>
  **Status legend:** no symbol means published documentation. `◇` means the capability is supported by Orderly but still requires DexBuilder development; it is not callable until a DexBuilder contract is published.
</Note>

## Platform surfaces

| Status | Surface | What it provides |
|---|---|---|
| Published | Trading API | Aden-compatible markets, orders, positions, margin, fills, and account data |
| ◇ | Wallet and settlement | Registration, Vault deposits, signed withdrawals, PnL settlement, and internal transfers |
| ◇ | Builder API | User attribution, Builder data, fee configuration, revenue settlement, referrals, and order tags |
| ◇ | Builder WebSocket | Builder-filtered operational and user data streams |
