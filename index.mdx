DexBuilder provides perpetual trading infrastructure for traders, application developers, and Builders launching their own trading frontend.

Use the Trading API for market data, orders, positions, and account data. Use the Builder guides for account registration, wallet authentication, asset flows, fee settings, and Builder administration.

## Documentation areas

| Area | Audience | Coverage |
|---|---|---|
| Trading API | Traders and application developers | Markets, orders, positions, margin, fills, and account data |
| Core integration flows | Wallet and frontend developers | Accounts, authentication, deposits, withdrawals, PnL settlement, and internal transfers |
| Builder API | Builders and backend developers | User data, fee settings, revenue settlement, order tags, referrals, and campaigns |
| WebSocket API | Frontend and trading-system developers | Public market data and private account events |
