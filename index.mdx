DexBuilder provides perpetual trading infrastructure for trading applications, wallets, brokers, exchanges, and branded DEXs.

Use these docs to integrate market data and trading, onboard users, move funds, settle accounts, configure fees, and operate a DEX.

<Warning>
  Builder, funds, and settlement endpoints marked **Preview** describe the target public interface. Do not use them in production until DexBuilder publishes a production base URL and removes the Preview label.
</Warning>

## Platform surfaces

| Surface | Audience | What it provides |
|---|---|---|
| Trading API | Traders and application developers | Markets, orders, positions, margin, fills, and private account data |
| Funds & Settlement API | Wallet and backend developers | Deposits, withdrawals, PnL settlement, transaction construction, and ledger history |
| Builder API | Project teams | Projects, user attribution, fee configuration, revenue, analytics, and webhooks |
| WebSocket API | Frontends and trading systems | Public market streams and private execution updates |

## Start here

<Steps>
  <Step title="Choose your integration path">
    Decide whether you are trading through an existing operator or building a DEX for your own users.
  </Step>
  <Step title="Develop in Sandbox">
    Use test credentials and test assets. Sandbox and production credentials must remain separate.
  </Step>
  <Step title="Complete the end-to-end flow">
    Validate registration, funding, trading, settlement, withdrawal, error handling, and reconciliation.
  </Step>
  <Step title="Pass the go-live checklist">
    Confirm security, maintenance behavior, monitoring, support, and production limits.
  </Step>
</Steps>
