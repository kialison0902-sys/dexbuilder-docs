Referral endpoints connect an account to a referral code and let an authorized Builder administer its referral program.


## Referral codes

| Method and path | Description |
|---|---|
| `GET /v1/public/referral/check_ref_code` | Check whether a referral code exists |
| `GET /v1/public/referral/verify_ref_code` | Verify a referral code |
| `POST /v1/referral/bind` | Bind a referral code to an account |
| `POST /v1/referral/create` | Create a referral code |

## Referral administration

| Method and path | Description |
|---|---|
| `GET /v1/referral/admin_info` | Get referral-code information |
| `POST /v1/referral/update` | Update a referral code |
| `POST /v1/referral/multi_level/admin` | Enable or configure multilevel referrals |
| `GET /v1/referral/multi_level/admin` | Get the multilevel-referral configuration |

## Binding rules

Referral binding is deterministic and auditable. Before binding an account, display whether the relationship is permanent, when updates are permitted, and when rebate rates take effect.
