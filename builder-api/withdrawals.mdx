## Withdrawal API

| Method and path | Description |
|---|---|
| `GET /v1/withdraw_nonce` | Get the withdrawal nonce |
| `POST /v1/withdraw_request` | Submit a signed withdrawal request |
| `GET /v1/asset/history` | Query withdrawal history |

## Withdrawal flow

1. read the withdrawable balance and supported destination network;
2. obtain the withdrawal nonce;
3. construct the EIP-712 message defined by the withdrawal schema;
4. display the asset, amount, fee, network, and receiver;
5. obtain the wallet owner's signature;
6. submit the withdrawal request;
7. track the asset-history record and destination transaction.

## Signing requirements

Use the EIP-712 domain, field order, nonce lifetime, timestamp unit, amount precision, fee behavior, status values, and retry rules returned for the active environment. Clients must sign the exact message required by that environment.
