Trading campaign endpoints support campaign discovery, performance reporting, eligibility checks, and account enrollment.


## Public campaign data

| Method and path | Description |
|---|---|
| `GET /v1/public/campaigns` | List campaigns |
| `GET /v1/public/campaign/ranking` | Get campaign ranking |
| `GET /v1/public/campaign/stats` | Get campaign statistics |
| `GET /v1/public/campaign/stats/details` | Get detailed campaign statistics |
| `GET /v1/public/campaign/user` | Get an account's campaign information |
| `GET /v1/public/campaign/check` | Check campaign eligibility |

## Enrollment

| Method and path | Description |
|---|---|
| `POST /v1/client/campaign/sign_up` | Enroll an authenticated account in a campaign |

## Campaign rules

Publish the campaign window, eligible products, volume calculation, ranking rules, reward terms, and account restrictions before enrollment opens.
