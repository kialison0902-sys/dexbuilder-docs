Builder information and fee-revenue endpoints support configuration checks and daily reconciliation.


## Builder information

| Method and path | Description |
|---|---|
| `GET /v1/broker/broker_info` | Get Builder fee-tier information |

The response identifies the Broker ID, active fee tier, base maker and taker rates, and fee-revenue configuration.

## Daily fee revenue

| Method and path | Description |
|---|---|
| `GET /v1/broker/daily_fee_revenue` | Get the Builder's daily fee-revenue history |

## Reconciliation

Reconcile daily fee revenue against Builder volume and account fee settings. Treat the daily fee-revenue response as the authoritative Builder revenue record.
