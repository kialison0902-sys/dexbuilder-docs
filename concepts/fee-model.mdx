## Fee components

| Component | Paid or received by | Description |
|---|---|---|
| Protocol base fee | DexBuilder | Base infrastructure trading fee |
| Builder fee | Builder | Builder-defined margin or maker rebate |
| Effective user fee | User | Final maker or taker rate shown to the user |
| Referral share | Referrer/referee | Portion of Builder economics allocated to referral participants |
| Funding payment | Long or short account | Periodic transfer between market sides; not a trading fee |
| Liquidation fee | Liquidated account | Liquidation and insurance-fund charge |
| Network/withdrawal fee | Withdrawing user | Chain messaging, gas, and processing charges |

## Rate representation

DexBuilder API schemas use decimal rates consistently:

`0.0005 = 0.05% = 5 bps`

Clients must not assume a field uses bps unless its schema explicitly says so.

## User disclosure

Before trading, display the effective rate returned by the Trading API. Display the withdrawal fee returned by the withdrawal request flow before the wallet owner signs.
