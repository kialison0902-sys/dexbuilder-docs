## Production activation

1. Complete security and architecture review.
2. Confirm production chains, assets, contract addresses, and signing domains.
3. Create new production credentials with least privilege.
4. Confirm fee policy, user disclosure, and Builder revenue-settlement configuration.
5. Execute the full flow with a controlled small amount.
6. Enable monitoring and on-call escalation before opening access.

## Required monitoring

- API availability, latency, and error rate;
- WebSocket connection, sequence gaps, and event lag;
- order rejection and reconciliation breaks;
- margin and liquidation anomalies;
- deposit, withdrawal, and settlement duration;
- Builder data-stream gaps after that surface is published;
- Builder volume and daily fee-revenue discrepancies.

## Launch evidence

For each published surface, retain sanitized identifiers and evidence for the first production registration, deposit, fill, fee, settlement, withdrawal, and daily revenue record. Remove secrets and full signatures.
