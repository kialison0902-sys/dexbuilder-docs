<Warning>DexBuilder has not published these Builder operations. Orderly reference paths are shown for development alignment.</Warning>

## Target sources

| Orderly reference | Use |
|---|---|
| `GET /v1/broker/broker_info` | Builder information and settlement configuration |
| `GET /v1/broker/daily_fee_revenue` | Daily Builder fee revenue |
| `GET /v1/volume/broker/daily` | Daily Builder volume |
| `GET /v1/public/volume/stats` | Public volume statistics |

Revenue reporting must use the final settlement fields returned by the platform. DexBuilder has not confirmed a public payout-creation API, fill-level revenue ledger, payout state machine, or generic payout resource, so none is documented here.
