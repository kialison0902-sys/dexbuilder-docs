<Warning>This is an onboarding requirement, not a published DexBuilder API flow.</Warning>

## Target setup

1. connect an organization-controlled administrator wallet;
2. complete Builder ownership and contact verification;
3. obtain the Builder identifier and approved administrative access;
4. configure the supported networks, collateral, markets, and fee policy;
5. create separate Sandbox and production credentials when those environments are available;
6. verify the Builder record through the DexBuilder equivalent of `GET /v1/broker/broker_info`.

DexBuilder has not confirmed Orderly-style Project CRUD. The documentation therefore does not define `project_id`, project creation endpoints, deployment APIs, or webhook configuration.
