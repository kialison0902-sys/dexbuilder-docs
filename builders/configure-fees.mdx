<Warning>The paths on this page are Orderly references and require a DexBuilder implementation.</Warning>

## Target operations

| Orderly reference | Purpose |
|---|---|
| `GET /v1/broker/fee_rate/default` | Read default maker and taker fee rates |
| `POST /v1/broker/fee_rate/default` | Create default fee rates |
| `POST /v1/broker/fee_rate/set_default` | Update default fee rates |
| `POST /v1/broker/fee_rate/set` | Set user-specific fee rates |
| `GET /v1/broker/user_info` | Read attributed-user and fee information |

The current Trading API fee endpoint remains the source for an authenticated user's effective perpetual trading rate. Builder fee administration is a separate `◇` surface.

DexBuilder must document rate units, precision, minimums, authorization, batch behavior, effective time, and read-after-write behavior before publication.
